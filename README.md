# АКПП911 — лендинг (Vue 3 + Vite)

Лендинг собран по ТЗ: тёмно-синяя палитра с золотыми акцентами, все блоки
(хедер, hero, услуги, модели/коды трансмиссий, прайс, цифры, преимущества,
отзывы, этапы работы, контакты, футер), анимации (fade-in при скролле,
shimmer, счётчики, параллакс в hero, вращение иконок).

## Запуск

```bash
npm install
npm run dev       # локальный сервер разработки
npm run build      # сборка в dist/
npm run preview    # предпросмотр собранной версии
```

Требуется Node.js 18+.

## Где редактировать контент

Почти весь текстовый контент, цены, отзывы и контакты собраны в одном файле:

```
src/config/siteData.js
```

Там же — плейсхолдеры, помеченные `// TODO`, которые нужно заменить перед
публикацией:

- `CONTACTS.phoneDisplay` / `phoneHref` — реальный номер телефона
- `CONTACTS.whatsappHref` / `telegramHref` — реальные ссылки на мессенджеры
- `CONTACTS.address` — реальный адрес СТО
- `CONTACTS.mapEmbedSrc` — embed-ссылка на Яндекс.Карту с меткой вашего адреса
  (взять на yandex.ru/map-constructor или через "Поделиться" → "Код для сайта")

## Где фото/видео

Все места под контент отмечены компонентом-плейсхолдером с пунктирной рамкой
(`src/components/PhotoPlaceholder.vue`). Чтобы вставить реальное фото, замените
`<PhotoPlaceholder label="..." ratio="..." />` на обычный `<img src="..." />`
с тем же классом-контейнером, либо на `<video>` для видео.

Места под контент:
- Hero — фон с цехом/разобранной АКПП
- Блок «О сервисе в цифрах» — фото мастера у стенда
- Отзывы — аватары клиентов

Для галереи «До / После» в текущей версии отдельного блока нет — в ТЗ он
упомянут как часть визуальных блоков, но не выделен в отдельную секцию
структуры лендинга. Если нужен отдельный блок-карусель «До / После» — скажите,
добавлю.

## Форма заявки

Форма в разделе «Контакты» валидируется на клиенте (имя, телефон, согласие на
обработку персональных данных). Отправка на бэкенд не подключена — в
`src/components/ContactsSection.vue` есть отметка `// TODO`, куда добавить
запрос к вашей CRM, Telegram-боту или email-сервису.

## Что сознательно не делал в этой версии (по вашей просьбе)

- SEO: title/description по страницам, sitemap.xml, robots.txt, полная
  Schema.org-разметка — не настраивал.
- Юридика: добавил только чекбокс согласия на обработку персональных данных
  в форме (без него принимать заявки с личными данными в РФ нельзя). Отдельной
  страницы политики конфиденциальности, условий гарантии, публичной оферты —
  нет, в футере просто заглушка-ссылка.
- Аналитика (Google Analytics / Яндекс.Метрика) — не подключена.
- Настоящие фотографии — используются плейсхолдеры, см. выше.

## Структура проекта

```
src/
  components/       — секции лендинга и переиспользуемые компоненты
    icons/          — простые SVG-иконки (без внешних библиотек)
  composables/       — fade-in директива, анимация счётчиков
  config/
    siteData.js      — весь редактируемый контент и контакты
  assets/styles/      — CSS-переменные (палитра, шрифты) и глобальные стили
  App.vue
  main.js
```
